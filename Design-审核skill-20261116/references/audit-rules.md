# 审核规则与来源

## 1. Logo和品牌口号

| ID | 类别 | 要求 |
| --- | --- | --- |
| LOGO-01 | logo | 对照包内滴滴出行横向反白Logo，核对图形、文字及资产身份，不用近似图标/普通文字替代。缺其他版本对照依据时说明无法核实，不断言其必然违规。 |
| LOGO-02 | logo | 素材内容完整，无裁切、缺字、缺失图形或删除内部构成。不检查缩放比例、坐标、间距或保护区。 |
| SLOGAN-01 | slogan |「去往每一种生活」固定单行反白素材，文字无错漏、改写、替换或拆行；不审核活动文案。 |
| SLOGAN-02 | slogan | 字形、底线及内容完整性与原始口号一致。不检查其尺寸、与Logo相对高度、位置或主次信息层级。 |

## 2. 成品交付（category=size）

本节来自用户当前明确要求，取代之前的成品导出规则；不是原品牌PDF条款。

| ID | 硬性要求与核对方式 |
| --- | --- |
| DELIVERY-01 | 同一规格同时提供有效PNG和SVG，内容为同一成品。单张PNG或SVG缺配对文件时不通过。 |
| SIZE-01 | 明确宽×高mm，按1:1制作；不得用缺单位数值、文件名、截图或viewBox猜最终物理尺寸。缺目标时保留实测值并因无法核实判不通过。 |
| PNG-01 | 宽、高分别计算 `floor(mm÷25.4×150+0.5)`，使用十进制四舍五入，不用银行家舍入；至少1px。实际宽高须与结果一致，并在报告标注像素尺寸。210×297 mm→1240×1754 px。 |
| PNG-02 | PNG导出密度150 PPI；pHYs横纵5906像素/米、单位米，对应约150.0124 PPI是正常整数元数据取整。此项检查成品输出设置，不评定源素材原生清晰度。 |
| SVG-01 | 根width、height显式使用mm且等于成品目标。内部viewBox可采用自己的坐标范围，不要求其数值等于毫米数。 |
| SVG-02 | 不保留未转曲的活动文字对象text/tspan/textPath。foreignObject等复杂内容须实际核对，不能猜已转曲。title/desc/metadata中的说明文字不作为可编辑设计文字。 |
| SVG-03 | 图片嵌入文件（如有效data URI），无丢失的相对路径、绝对路径、网络图片、外部use、样式表/字体等渲染依赖。内部#id引用可以使用；点击跳转目标不等于外部渲染依赖。嵌套SVG、CSS及动态内容需完整检查，不访问或执行不可信外部资源。 |
| SVG-04 | 实际设计文字已转成轮廓路径，字形/内容正确；没有text只说明必要条件，不证明全图位图封装已完成转曲。不额外新增“所有Logo必须有矢量源”的要求。 |
| CONTENT-01 | 实际渲染PNG、SVG核对文案、图像、品牌元素与可见内容一致，无漏图、漏字、替代字形。只比较本次两种交付，不要求项目模板或另附设计稿。 |
| WATERMARK-01 | PNG和SVG均无系统、试用、素材平台等水印；既定品牌Logo/口号及活动文案不自动认定为水印。须查看实际画面，不能因文件名、id或元数据出现watermark一词就判有水印。 |

SVG物理尺寸与内部坐标是两个概念；嵌套坐标及样式会改变实际呈现，遇到复杂内容需渲染核对。[SVG坐标与单位规范](https://www.w3.org/TR/SVG2/coords.html)、[SVG嵌入内容规范](https://www.w3.org/TR/SVG2/embedded.html)。

## 3. 清晰度只作说明

素材清晰度不足、低源像素、放大后的模糊/锯齿或无法评估原生清晰度，全部写quality_notes；不生成失败检查，不影响总result，不阻止导出，不要求另行批准。用户没有指定源位图最低PPI，不自行新增阈值。PNG成品必须按150 PPI正确输出，但写入150 PPI元数据或插值放大不能证明源素材变清晰。

例如其他硬性检查均符合，备注“主视觉放大后略模糊”时，整体仍为通过。文字被替换、SVG缺图或PNG像素尺寸错误分别按对应硬性条款判断，不能与低清说明混淆。

## 4. 范围与证据

只保留Logo、口号、成品交付三类；不恢复通用版式、比例、元素位置、安全空间、字体品牌体系、文案事实或印前工艺审核。没有固定尺寸目录或尺寸数量上限。审核保持只读。

每条硬性结论须关联实际文件哈希与证据。只有静态检查尚不能证明的硬性要求，标不通过并注明未执行/缺证据；这不适用于清晰度说明。裸栅格可以作品牌视觉核对，缺生成端引用不单独判失败，也不能把源素材哈希当成品已正确呈现的证明。
